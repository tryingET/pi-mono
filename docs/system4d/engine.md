# System4D — Engine

## Invariants
- The repo must always explain why the fork exists.
- Repo-local decisions outrank stale upstream proposal context once the fork path is chosen.
- Work-items, diary, and active handoff must agree on the current execution slice.
- Upstream import/sync behavior must be explicit before substantial code divergence begins.
