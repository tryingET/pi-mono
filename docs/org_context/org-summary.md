# Org Summary

- Org purpose: keep long-lived divergence in an explicit `softwareco/fork` home instead of smuggling it through upstream issue follow-up.
- Non-negotiables: no secrets in git; branch + MR workflow; `docs/_core/**` stays immutable; each fork repo must explain why it exists.
- Approval/consent notes: repo-local decisions should capture when upstream fit failed and what local authority now governs the work.
