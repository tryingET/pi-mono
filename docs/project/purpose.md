# Purpose

Provide a deliberate fork-lane repository for `pi-mono` work once upstream issue follow-up is no longer the right operating model.

In scope:
- repo-local governance for the fork
- upstream import/sync policy
- future local DSPY-oriented implementation work

Out of scope for the bootstrap phase:
- pretending this is still only an upstream issue queue
- landing hidden divergence without a recorded decision
- broad code import before sync posture is documented
