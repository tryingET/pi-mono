# Strategic Goals

- Goal: Keep fork rationale and upstream boundary explicit.
  - Metric: every major divergence in this repo points back to a repo-local decision rather than stale upstream issue context.

- Goal: Turn the abandoned upstream DSPY proposal set into a local roadmap.
  - Metric: each major DSPY concern is represented in repo-local planning artifacts before implementation begins.

- Goal: Create a reproducible path from upstream seed to local validated divergence.
  - Metric: import/sync posture, validation expectations, and the first executable slice are all documented before substantial code lands.
