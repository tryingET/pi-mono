# Learnings

Capture what works, what does not, and what should be tried again next time.

## Structure

- `YYYY-MM-DD-topic.md` — dated learning entries
- link to TIPs if a learning should propagate beyond this repo

## Template

```markdown
# [Topic]

## Context
What situation triggered this learning?

## Discovery
What did we learn?

## Evidence
How do we know it is true?

## Application
Where else does this apply?
```
